1
Paso 1 · Observa el patrón

¿Cómo cambia la sucesión?

⏱️ ~10 min

Una sucesión es una lista ordenada de números que sigue una regla. Para descubrirla, compara términos consecutivos y pregúntate: ¿se suma siempre lo mismo o se multiplica siempre por lo mismo?

Si se suma o resta lo mismo

5, 8, 11, 14, ...

La diferencia es constante: +3. Es aritmética.

Si se multiplica o divide por lo mismo

2, 6, 18, 54, ...

La razón es constante: ×3. Es geométrica.

Tu primer paso

Resta términos vecinos. Si las diferencias son iguales, es aritmética. Si no, divide cada término entre el anterior: si los cocientes son iguales, es geométrica.

2
Paso 2 · Ejemplo geométrico

Sucesión Geométrica

⏱️ ~15 min

Contexto

En una campaña de reforestación, se plantan 3 árboles el primer día. Cada día, el número de árboles plantados se duplica respecto del día anterior.

Secuencia

3, 6, 12, 24, 48, ...

Pregunta orientadora

¿Cómo se obtiene cada término a partir del anterior? ¿Qué relación existe entre cada término y el que le sigue?

Resuelve paso a paso

  • 1. Identifica el primer término: a₁ = 3.
  • 2. Divide términos vecinos: 6 ÷ 3 = 2 y 12 ÷ 6 = 2.
  • 3. La razón constante es r = 2; por eso es geométrica.
  • 4. Usa la fórmula aₙ = a₁ · rn−1.
  • 5. Para el día 6: a₆ = 3 · 25 = 96 árboles.

Representación

a₁ = 3, r = 2, aₙ = 3 · 2n−1

3
Paso 3 · Ejemplo aritmético

Sucesión Aritmética

⏱️ ~15 min

Contexto

En la semana 1, un estudiante tiene $50 ahorrados. Cada semana agrega $20. ¿Cuánto tendrá en la semana 6?

Secuencia

50, 70, 90, 110, 130, ...

Pregunta orientadora

¿Qué ocurre con cada término respecto al anterior? ¿Se suma o se multiplica siempre la misma cantidad?

Resuelve paso a paso

  • 1. Identifica el primer término: a₁ = 50.
  • 2. Resta términos vecinos: 70 − 50 = 20 y 90 − 70 = 20.
  • 3. La diferencia constante es d = 20; por eso es aritmética.
  • 4. Usa la fórmula aₙ = a₁ + (n − 1)d.
  • 5. Para la semana 6: a₆ = 50 + (6 − 1) · 20 = $150.

Representación

a₁ = 50, d = 20, aₙ = 50 + (n − 1) · 20

4
Paso 4 · Practica y comprueba

¿Cuál regla debes usar?

⏱️ ~10 min
Aspecto Sucesión Geométrica Sucesión Aritmética
Regla Se multiplica por una cantidad constante. Se suma una cantidad constante.
Razón / Diferencia Razón: r Diferencia: d
Ejemplo 3, 6, 12, 24, ... 50, 70, 90, 110, ...
Crecimiento Puede crecer muy rápido. Crecimiento constante y lineal.
Fórmula aₙ = a₁ · rⁿ⁻¹ aₙ = a₁ + (n-1)d

Idea clave geométrica

En la sucesión geométrica, cada término se obtiene multiplicando por la razón; por eso el crecimiento puede ser explosivo.

Idea clave aritmética

En la sucesión aritmética, cada término se obtiene sumando la diferencia; por eso el crecimiento es constante.

Practica por tu cuenta

  1. Clasifica: 7, 11, 15, 19, ... ¿cuál es su diferencia?
  2. Clasifica: 5, 15, 45, 135, ... ¿cuál es su razón?
  3. Encuentra el término 8 de 4, 9, 14, 19, ...
  4. Encuentra el término 5 de 2, 6, 18, 54, ...
Mostrar respuestas para comprobar

1. Aritmética, d = 4.

2. Geométrica, r = 3.

3. a₈ = 4 + (8 − 1) · 5 = 39.

4. a₅ = 2 · 35−1 = 162.

Resumen final

Recuerda estos pasos

Compara términos vecinos. Si la diferencia es constante, usa la regla aritmética. Si el cociente es constante, usa la regla geométrica. Sustituye la posición n en la fórmula correspondiente y verifica tus operaciones.
