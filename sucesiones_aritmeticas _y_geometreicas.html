Unidad 1: Sucesiones Aritméticas y Geométricas

Sucesión Aritmética

Término general: an = a1 + (n - 1)d

Sucesión Geométrica

Término general: an = a1 · r(n-1)

Resumen Comparativo

Característica Sucesión Aritmética Sucesión Geométrica
Operación clave Suma / Resta de una constante ($d$) Multiplicación / División por una razón ($r$)
Fórmula del enésimo término an = a1 + (n - 1)d an = a1 · rn-1
Suma de los n primeros términos Sn = [n · (a1 + an)] / 2 Sn = [a1 · (rn - 1)] / (r - 1)
